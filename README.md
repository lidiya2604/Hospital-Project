# Hospital Management System

A web-based hospital appointment booking system that allows patients to register, view doctors, and schedule appointments.

## 🚀 Features
- Patient registration
- Doctor listing
- Appointment booking
- Java backend support

## 🛠️ Technologies Used
- Java
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Clone the repository
2. Open the project in your IDE
3. Run the Java backend
4. Launch index.html
